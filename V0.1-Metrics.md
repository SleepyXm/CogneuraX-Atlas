# V0.1 retrieval metrics

## Status and evidence boundary

This file preserves two different evidence sets rather than combining them into one accuracy claim:

- The current evidence-region and prompt-partition pass was measured in Synapse on 8 September 2026, then reconciled into Atlas. The implementation and controls now match, but Atlas has not independently rerun the complete 420-query benchmark.
- The historical standalone Atlas V0.1 evaluation used the removed document-facet routing and whole-collection sparse fallback architecture. It remains below for comparison only.

These metrics evaluate returned evidence, not generated answers. Atlas does not call a user's answer model.

## Current evidence-region reference run

The corpus contains all 35 multi-paragraph Wikipedia articles in Stanford's SQuAD 2.0 development set. Its 1,204 source paragraphs became 2,290 ordered Docling evidence regions. The evaluation contains 420 questions: 140 answerable, 140 indexed-article adversarial, and 140 missing-source.

The prompt pass preserves the intact grammatical question for dense BGE retrieval, copies content terms to FastEmbed BM25, and requires numbers and multiword proper names to occur somewhere inside the dense-matching region set. It does not call a model, paraphrase, or infer entities. Exact anchors constrain the semantic community rather than every final region.

### Retrieval controls and threshold sweep

Dense similarity admits every region at or above `0.55`. FastEmbed `Qdrant/bm25` uses English stemming, `k=1.2`, `b=0.75`, `avg_len=256`, a 40-token maximum, and Qdrant's IDF modifier. BM25 searches only the dense region IDs. There is no whole-collection fallback, fusion, reranker, verifier, or query-time LLM.

The selected V0.1 operating point is `12.5`: 124/140 answer-bearing, the expected source present anywhere for 128/140, the correct source first for 127/140, and 131/280 unsupported questions rejected. Compared with `5.0`, it trades six answer-bearing results for 51 additional correct rejections.

The exact no-loss ceiling is `6.15401`; moving above it removes the first previously retrieved answer. If answerable and unsupported questions are weighted equally, the best observed balance is around `16.99`. The score distributions overlap completely: the highest false adversarial score is `62.636112`, above the highest answer-bearing score of `60.457485`, so no BM25 threshold can reject every unsupported question while retaining measured answer evidence.

### Runtime measurements

The first generation took 92.0 seconds (24.9 regions/s); a repeated cold-process run took 80.47 seconds (28.46 regions/s). Cached TEI artifacts reached ready in about 1.6 seconds. The first full retrieval took 145.4 ms; the next 20 averaged 18.0 ms.

Raw prompt-pass evidence for all 280 unsupported questions is preserved in `testdata/outputs.json`. The SQuAD source SHA-256 values are `80a5225...77182d8` for the development set and `68dcfbb9...dede002` for the training set.

The separate spaCy entity-routing experiment was rejected. Hard entity constraints reduced the smoke-test answer result to 8/12; entity union recovered only 9/12, and facet inspection mislabeled headings as organisations. It is not part of Atlas.

## Corpus construction

The frozen fixture is `testdata/v0.1-corpus.json`; the compact per-query output is `testdata/v0.1-results.json`.

- Source: Stanford Question Answering Dataset 2.0 development set
- Source SHA-256: `80a5225e94905956a6446d296ca1093975c4d3b3260f1d6c8f68bc2ab77182d8`
- Licence: CC BY-SA 4.0
- Sampling seed: `104729`
- Documents: 10 randomly selected article topics
- Indexed content: 10 randomly selected sections per document
- Resulting chunks: exactly 10 Docling chunks per document
- Answerable questions: one independently authored SQuAD question from each indexed section
- Hard negatives: two questions from withheld sections of the same article per document

Every hard negative has known answer spans in its withheld source section. Those spans were verified absent from the indexed document before the prompt map was frozen. This makes each negative topically related while ensuring the indexed content does not contain its labelled answer.

The fixture retains the original SQuAD question IDs, source section indexes, accepted answer spans, expected filenames, and withheld section indexes.

This is materially deeper than the discarded one-chunk run, but it is still not a complete corporate-document benchmark. It does not exercise PDFs, tables, scans, very long documents, or hundreds of overlapping documents.

## Answerable failures

Three answerable questions failed for different reasons:

1. `What types of European groups were able to avoid the plague?`
   The correct Black Death document ranked first, but Atlas returned the wrong chunk from it. This is a within-document sparse-selection failure.
2. `What was the name of the experiment that tested how life originated?`
   The expected University of Chicago document was absent; a Jacksonville chunk ranked first. This is a document-routing or fallback false positive.
3. `Where did the residents of Antioch flee to?`
   The expected Black Death document was absent; a Jacksonville chunk ranked first. This is another document-routing or fallback false positive.

One successful question, `Which country used to rule California?`, placed an Imperialism chunk first and the answer-bearing Southern California chunk second. A caller using only the first result would answer from the wrong source.

## Hard-negative failures

Of the 20 questions whose answer-bearing sections were withheld:

- 4 returned no chunks.
- 14 returned a chunk from the topically related document first.
- 2 returned an unrelated document first.

Among the 16 false positives, first-result BM25 scores ranged from `5.169163` to `16.677608`, with a mean of `11.022545`. Successful answerable first-result scores ranged from `6.589479` to `45.653946`, with a mean of `20.413631`.

The score ranges overlap. Rejecting every observed hard negative by raising the threshold above `16.677608` would also discard 38 of the 97 observed answerable successes. Keeping the lowest successful answer would retain 15 of the 16 hard-negative false positives.

Therefore, decimal precision or a single BM25 threshold cannot separate relevance from answerability:

```text
Question is about the document
        ↓
Dense routing selects it
        ↓
BM25 finds related sections
        ↓
The requested fact can still be absent
```

## Ingestion finding

The deeper corpus exposed a deterministic ingestion failure that the shallow corpus could not. Qwen repeatedly returned one `OVERVIEW` facet longer than BGE's 512-token input limit for the Imperialism document. The processor rejected the complete document on all three River attempts, correctly blocking generation activation.

The minimal correction keeps valid typed facets and skips only an individual facet that exceeds the embedding model's physical input limit. The corrected document then produced 10 chunks and completed ingestion. Retrieval behavior was not changed.

For the 10 successful effective dense passes, logged durations totalled 1,371.451 seconds:

| Dense stage | Result |
| --- | ---: |
| Mean per document | 137.145 s |
| Minimum | 79.941 s |
| Maximum | 188.835 s |

The three failed attempts consumed an additional 411.493 seconds before the correction. Sparse indexing completed all 100 chunks after the dense barrier opened; the first sparse job included a 929 ms cold model load, while the remaining nine jobs totalled 133 ms.

No implementation improvement caused the higher answerable score. The extended questions still originate from their source sections and commonly share useful vocabulary with them. The extended corpus improves confidence in multi-chunk selection and hard-negative behavior; it does not establish 97% production accuracy.

## Historical Atlas conclusion

V0.1 now has evidence for four separate weaknesses:

1. Semantic document routing can still admit the wrong document for a question.
2. BM25 can select the wrong section even after reaching the correct document.
3. Relevance scores cannot determine whether the requested fact exists.
4. The final evidence packet is not bounded, creating avoidable downstream context cost.

Future changes must be developed against a separate calibration set and judged using a fresh frozen holdout. The V0.1 corpus and expected results must not be edited to make an experiment look better.
